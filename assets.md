# Asset Inventory

The authoritative system & information asset inventory is **`inventory/systems.md`**
(systems, data classification, owner, location), with the device roster in
`inventory/devices.yaml`, network exposure in `inventory/endpoints.yaml`, and the
machine-readable data inventory in `compliance/data-inventory.yaml`.

This file exists as the top-level pointer; see those files for the current inventory.
Reviewed at least annually and on significant change (CC3.2, CC6.1). Last reviewed 2026-07-29.
